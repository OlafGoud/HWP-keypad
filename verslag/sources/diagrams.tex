\section{Ontwerpen}
\subsection{Buzzer}
Wat vooral te zien is dat er dat bij ons ontwerp geen rekening is gehouden met de tijdsduur van elke staat. Wanneer de timer van de staat groter is dan 0, zal de staat richting zichzelf gaan, zoals te zien is in de State Machine Viewer in Quartus. Wanneer de timer op 0 staat, zal de staat wel veranderen. Ook is in de State Machine Viewer the zien dat er een mogelijkheid is om naar de staat "buzz1" te gaan via "gap" of "buzz2", terwijl hier geen rekening mee is gehouden.
